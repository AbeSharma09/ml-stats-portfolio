# Customer Cashflow Intelligence & Balance Forecasting Engine

## Overview

This project demonstrates an end-to-end machine learning workflow for forecasting customer account balances one month ahead. It uses synthetic customer cashflow data to simulate banking behavior across multiple financial personas and compares regression models using time-aware validation.

## What this project includes

- Synthetic data generation for customer cashflow and balance history
- Feature engineering with lag variables and month-aware signals
- Forecasting of next-month balance using regression models
- Model selection and evaluation using MAE, RMSE, and R-squared
- Persistence of the final trained model as `balance_forecasting_model.pkl`

## Dataset

The synthetic dataset is generated by `data generator.py` and saved as `balance_forecasting_persona.csv`.

Each record includes a monthly summary for a customer with fields like:

- `customer_id`
- `persona`
- `month`
- `salary`
- `other_credit`
- `total_credit`
- `total_debit`
- `emi`
- `balance`

Customer personas modeled in the data generator:

- `stable`
- `overspender`
- `saver`
- `debt_heavy`
- `volatile`

The generator simulates realistic behavior such as salary growth, festival spending spikes, EMI burden, emergency expenses, and income shocks.

## Notebook workflow

The main analysis is contained in `customer_balance_forecasting_pipeline.ipynb` and includes:

1. Data loading and inspection
2. Synthetic data exploration by persona and time
3. Feature engineering for forecasting
4. Label creation for next-month balance prediction
5. Model pipeline definition and comparison
6. Time-based train/test split and cross-validation
7. Model evaluation and result reporting
8. Saving the selected model

## Modeling approach

The notebook evaluates multiple regression algorithms, including:

- ElasticNet Regression
- K-Nearest Neighbors Regressor
- Random Forest Regressor

Preprocessing steps include:

- One-hot encoding for `persona`
- Scaling numeric features for ElasticNet and KNN
- Passing numeric features unchanged for Random Forest

## Evaluation metrics

Forecast performance is measured using:

- `MAE` (Mean Absolute Error)
- `RMSE` (Root Mean Squared Error)
- `R-squared` (Coefficient of Determination)

These metrics help assess how close predicted balances are to actual next-month balances.

## Setup and usage

1. Open the project folder:

```bash
cd "Customer Cashflow Intelligence & Balance Forecasting Engine"
```

2. Install required packages:

```bash
pip install pandas numpy matplotlib seaborn scikit-learn joblib
```

3. Open and run the notebook:

```text
customer_balance_forecasting_pipeline.ipynb
```

4. Re-run the generator if you want fresh synthetic data:

```bash
python "data generator.py"
```
